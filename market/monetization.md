## 2. Free-to-Pro Conversion Triggers (Upgrade Moments)

These are the precise in-app moments where users are most likely to upgrade:

| Trigger | Context | Upgrade Prompt |
|---|---|---|
| **3rd email address limit** | User tries to add a 3rd email | *"Connect unlimited emails with Pro."* |
| **Automated breach alert locked** | New breach detected but alert is Pro-only | *"A breach was found — upgrade to get real-time alerts."* |
| **Digital Footprint locked** | User clicks "Footprint" tab | *"See your full digital map with Pro."* |
| **Cleanup assistant locked** | User clicks on an inactive account | *"Guided cleanup is a Pro feature."* |
| **Scan limit reached** | 2nd manual breach check of the month | *"Upgrade for unlimited, automated monitoring."* |

## 5. Churn Reduction Strategy

| Tactic | Implementation |
|---|---|
| **Continuous value delivery** | Weekly breach & scan digest email (Pro) keeps users engaged even without opening app |
| **Inactivity re-engagement** | Email at 7, 14, 30 days of inactivity: "Your security score changed" |
| **Annual plan incentive** | Offer annual plan switch at 3-month mark to reduce monthly churn |
| **Feature release notifications** | In-app changelog with "What's new" banner after each release |
| **Exit survey on downgrade/cancel** | Capture cancellation reason; offer pause-plan instead of cancel |
